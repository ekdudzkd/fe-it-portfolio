## 한 줄 역할

**실제 서울 지리 데이터 기반 3D 월드 구축 및 렌더링 · 로딩 성능 최적화 (Three.js)**

## 1. 실제 서울 지도로 3D 월드 만들기

- **실제 서울 도로망 파이프라인**: OpenStreetMap 원본 → 변환 스크립트(`frontend/scripts/export-roads.mjs`) → `roads.json`.
  중심선에서 차도 겉면(거리장) · 차선 · 교차로 노드 · 정지선을 계산. 겹친 조각 · 다리 끝 끊김 · 막다른 길 정리까지 8단계 (10-22).
- **랜드마크를 실제 경위도 위치로**: 건물 크기 배율, 퀘스트 목표 · NPC · 과일 · 레이스 코스를 새 위치에 맞춰 다시 놓음.
- **한강 다리**: 같은 곡률을 공유하는 한 덩어리 상판, 땅 차선과 맞춘 상판 차선, 진입로, 교각 줄이기, 수상택시가 교각에 부딪혀 미끄러짐.
- **2호선 트램 순환선**: OSM 본선 순환선 · 정류장 데이터, 도로와 겹치지 않는 전용 궤도, 아스팔트에 박힌 레일, 고가 승강장, 동숲 기차역 느낌 정류장.
- **지역 꾸미기**: 송파 주거 단지, 농장섬(서쪽 하천 · 아치 돌다리 · 풍차 · 밤 가로등), 강원 아일랜드(리조트 수영장 · 바 · 불꽃놀이), 여의도 광장, 노량진 골목 · 은행 광장, 장미공원, 한강공원 수영장(잠실 · 난지), 남산 자물쇠, 암사동 움집, 김포공항.

## 2. 로딩 · 렌더링 성능

- **먼저 쟀다**: 첫 로딩을 구간별로 재 보니 **섬 짓기가 62%**. (로그인 뒤 이어 받기 동시 처리는 0.1초뿐이라 원인 아님)
- **땅 판정을 배포 빌드 때 미리 계산 (굽기)** → 약 **−2초** (!1960)
- **GPU 업로드를 로딩 화면 동안 나눠서** (!1940)
- 섬 메시를 **인덱스 지오메트리**로, 상자 합치기를 **Float32 배열**로, 물가 절벽(`buildBanks`) 계산 빠르게, 장미공원 돌길 등 섬 짓기 계산 굽기
- 그 전에: 섬 화면 렉 줄이기, 미니맵 확대 화질
- **측정값 (MR마다 같은 조건 전 / 후 번갈아 측정)**
  - 운영 100%까지 약 11.5~12.2초 중 `new World()` 7.2~8.1초 = 62% (11-09)
  - !1940 GPU 업로드 분할: 타이틀 멈춤 3.3~3.9초 → 없음 (총 시간은 그대로)
  - !1960 땅 판정 굽기: 섬 짓기 7.8 → 5.75초, 100%까지 −2초, 픽셀 diff 0
  - !1962 셰이더 미리 컴파일: 첫 방문 · 밤 2.8초 멈춤 → 없음
  - !1972 길찾기 제너레이터(프레임당 4ms): 1.96~2.36초 멈춤 → 최대 0.19초
  - !1990 Float32Array 합치기: 섬 짓기 0.66~0.8배
  - !2039 인덱스 지오메트리: 690 → 440MB, 100% 10.0 → 9.3초, 해시 2,701/2,703 동일
  - !2093 굽기 2탄: 섬 짓기 4.82 → 4.04초, 100% 10.75 → 9.95초
  - ⚠️ 측정일이 달라 "처음 12초 → 지금 N초" 처럼 이어 붙인 총 시간은 없음. 필요하면 같은 날 두 커밋을 다시 재야 함

## 3. 게임 시스템 · 콘텐츠

- **퀘스트 · 온보딩**: 메인 스토리 장 재구성(석촌호수 산책 등), 주민 편지 퀘스트 14종, 첫 튜토리얼 · 코치마크, 퀘스트 완료 연출, 14일 연속 출석 · 달력, 숨은 미션
- **캐릭터**: 2등신 비율(큰 둥근 머리 · 짧은 종 모양 몸), 팔꿈치 · 무릎 관절과 자세, 눈 깜빡임, 1인칭(머리만 숨김), 성별 수영복 · 수영장 들어갈 때 자동 착용, 옷 직접 그려 만들기, 피팅룸
- **실내 카메라**: 캐릭터 따라가기, 드래그 · 휠, 벽 밖으로 나가면 그 벽만 반투명, F 1인칭 · C 방 전체
- **송파 주거 단지**: 분양 · 입장 · 층 선택 · 기본 가구 서버 연동
- **HUD · UI**: 미니맵(원형 · N 표식 · 편지 목적지), 채팅창 정리, 로딩 화면 새싹 애니메이션
- **차고 · 차 그리기**: 페인트 통(영역 채우기), 동글 세단 차체 + 그림 대표 색
