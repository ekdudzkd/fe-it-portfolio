- UI(채팅 · 알림)가 가리면 정리하고 찍기, 낮 시간대 기본 + 노을/밤은 따로 한 컷

## 🥇 꼭 찍을 것 (핵심 작업 = 포트폴리오 메인 이야기)

### 핵심 작업 1. 실제 서울 지도 3D 월드
1. **하늘에서 내려다보는 서울 전체** (미니맵/지도 열기 → 실제 서울 모양 · 한강 · OSM 출처 표기) — 10초
2. **차로 실제 도로 달리기**: 교차로 · 차선 · 정지선이 보이게 한 구간 — 20초
3. **한강 다리 건너기** (차나 걸어서): 곡선 상판 · 진입로 · 교각 — 15초
4. **수상택시가 교각 사이 지나가기** (부딪혀 미끄러지는 것까지 되면 좋음) — 10초
5. **2호선 트램 순환선**: 정류장 + 트램이 도로 옆 전용 궤도를 달리는 장면 — 15초
6. **랜드마크 실제 위치**: 광화문광장 · N서울타워 · 숭례문 · 시청을 차례로 짧게 (택시 이동 가능) — 각 3–5초 몽타주

### 핵심 작업 2. 로딩 성능 (숫자가 필요한 부분)
7. **첫 접속부터 섬 도착까지 전체 로딩 녹화** (새싹 로딩 화면 포함) — 시계 보이게, 강력 새로고침(Ctrl+Shift+R)으로 3번
8. **개발자도구 Performance / Network 캡처**: 로딩 구간 스크린샷 → 상세 페이지 `[전 / 후 로딩 시간]` 칸에 쓸 현재 값
   - "전" 값은 서버 말고 로컬에서 최적화 이전 커밋(!1940 · !1960 이전)을 띄워 재면 됨 — 서버 닫혀도 가능, 나중에 해도 됨

### 핵심 작업 3. 멀티플레이 미니게임 (사람 모일 때만 찍을 수 있음 → 제일 먼저 팀원과 약속)
